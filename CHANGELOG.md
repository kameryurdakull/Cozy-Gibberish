# Changelog

## 2.0.0 - 2026-07-30

- Added weighted onset-vowel-coda phonotactic profiles and Unicode/rich-text tokenization.
- Added vowel harmony, repetition control and source-range-aware word/phrase planning.
- Added sampled prosody curves, weighted style stacks, voice morphing and speech sequences.
- Added hybrid procedural/sample grain synthesis and cancellation-aware rendering.
- Added DSP-time scheduling, equal-power dual-source crossfades and future-timestamp events.
- Added pause, resume, seek, bounded queue overflow policies and AudioMixer ducking.
- Added thread-safe LRU PCM cache, UniTask prewarming and bounded render scheduler.
- Added allocation-free audio-thread ring-buffer streaming output.
- Added Voice Lab with waveform, spectrum, A/B morph, seed gallery, locked randomization and WAV export.
- Added batch WAV baking, profile validation/migration and network request serialization.
- Added TMP, dialogue, Localization, Timeline, Addressables and Burst integration samples.
- Added EditMode, PlayMode, cancellation, spectral and performance coverage.

## 1.0.0 - 2026-07-28

- Initial production package.
- Procedural formant synthesis with configurable oversampling.
- Deterministic punctuation-aware utterance planning.
- Voice profiles, style presets and per-request expressions.
- Priority playback queue, cancellation and typed Event Bus.
- Profile preview inspector and starter-kit setup wizard.
- Optional UniTask, VContainer and DOTween samples.
- EditMode coverage for determinism, DSP safety and event lifetime.
